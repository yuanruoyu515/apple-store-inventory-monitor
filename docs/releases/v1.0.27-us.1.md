# 果到雷达 · 美加阿版 v1.0.27-us.1

由 **yuanruoyu515** 维护，基于 suversal 上游 **v1.0.26**。一个 macOS 安装包支持美国、加拿大、阿联酋。

- 更新当前取货接口、持久浏览器会话、浏览器 UA / Client Hints、同城门店查询合并与缺项补查，减少旧版的重复请求和会话重建。
- 保留上游的系统代理、指定 Clash 节点和节点轮换设置。Clash 需要自己配置；软件不提供代理服务。不能保证消除 HTTP 541。
- 新增阿联酋五家 Apple Store、40 个官方 `AH/A` 型号，保留美国 269 家、加拿大 28 家门店及各自 40 个型号，三国料号不混用。
- 界面加入 [GitHub @yuanruoyu515](https://github.com/yuanruoyu515) 和 [Threads @realtimyry](https://www.threads.com/@realtimyry) 标签，保留上游源码入口。
- 保留旧版待公布状态、跨年日期、切换国家保护、Bark、声音与购物袋 / 商品页跳转；加入上游 Bark 参数和到货后暂停监控等改进。
- 新安装默认查询间隔为 60 秒；旧设置原样保留。美国以外不携带美国运营商参数。

## 下载与升级

| Mac | 文件 |
| --- | --- |
| Apple 芯片（M 系列） | `Apple-Store-Inventory-Monitor-US-macOS-arm64-1.0.27.zip` |
| Intel | `Apple-Store-Inventory-Monitor-US-macOS-Intel-1.0.27.zip` |

完全退出旧版，解压并替换“应用程序”中的 **`Apple Store Inventory Monitor US.app`**。保留 US 文件名、Bundle ID 和配置目录以兼容升级，原有监控、Bark 与声音设置会保留。需要已安装的 Chrome / Edge，并保持 Mac 唤醒。

安装包采用 ad-hoc 签名，没有 Developer ID 签名或 Apple 公证。首次打开被拦截时，到“系统设置 → 隐私与安全性”确认本应用后选择“仍要打开”。确认文件来自本仓库且 SHA-256 一致，仍无法打开时可执行：

```sh
xattr -dr com.apple.quarantine "/Applications/Apple Store Inventory Monitor US.app"
```
