# 果到雷达 · 美加阿版 v1.0.28-us.1

本次统一更新维护版图标：保留原雷达与苹果主体，左上角增加白色弧形角标和蓝色地球。应用、菜单栏、界面、DMG 和项目首页使用同一套标识。

- 重新生成 App 的 PNG、ICNS 和 ICO 图标，更新网页图标与界面标识。
- 更新项目实机截图和下载入口；DMG 继续提供 Applications 快捷图标，支持拖拽安装。
- 保持原文件名、Bundle ID 和配置目录，覆盖升级保留原来的监控、Bark、声音和查询间隔。

## 下载与升级

下载 **`Apple-Store-Inventory-Monitor-US-macOS-universal-1.0.28.dmg`**。Apple Silicon 与 Intel Mac 使用同一个安装包。

先从菜单栏完全退出旧版，打开 DMG，把 App 拖到 Applications 并替换同名应用，再从「应用程序」打开。需要已安装 Chrome 或 Edge，监控时保持 Mac 唤醒。

本版使用 ad-hoc 签名，没有 Developer ID 证书和 Apple 公证。首次打开如被 macOS 拦截，请先确认安装包来自本仓库、SHA-256 一致，再按 [README 的安装说明](https://github.com/yuanruoyu515/apple-store-inventory-monitor#下载与安装)处理。

## 功能范围

继续支持美国、加拿大、阿联酋的 iPhone 门店取货监控、声音与 Bark 提醒、页面跳转，以及可选 Clash 线路设置。功能基于 suversal 上游 v1.0.26 适配；图标更新不改变库存查询行为，仍不能保证消除 Apple HTTP 541。

完整说明见 [README](https://github.com/yuanruoyu515/apple-store-inventory-monitor#readme)，历史来源与修改记录见 [NOTICE](https://github.com/yuanruoyu515/apple-store-inventory-monitor/blob/us-edition/NOTICE)。继续按 GPL-3.0-or-later 发布，附件包含安装包、对应源码、发布说明与 SHA-256 校验文件。

Apple Silicon 和 Intel 两个架构各通过 342 项 Rust 测试，74 项前端测试、构建及 Clippy 检查通过。真实 App 已验证三国取货查询与新图标显示。通用 DMG 已验证双架构、挂载后的 App 签名、图标资源及 Applications 链接。
