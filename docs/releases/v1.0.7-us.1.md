# Apple Store Inventory Monitor US v1.0.7-us.1

新增 **iPhone Duo** 美国版库存监控，保留 iPhone 18 Pro / Pro Max 与原有门店、Bark、声音提醒设置。

- Duo 支持 256GB、512GB、1TB、2TB，以及 Night Sky、Star White 两种颜色，共 8 个美国 SKU。
- 美国离线目录从 32 个增加至 40 个 SKU，269 家门店保持可用。
- “刷新型号”的备用购买页包含 Duo；型号搜索输入 `Duo` 即可筛选。
- 官方 SKU 已于 2026-10-15 对照 [Apple 美国购买页](https://www.apple.com/shop/buy-iphone/iphone-duo) 核对。

## 下载与安装

- Apple 芯片 Mac：`Apple-Store-Inventory-Monitor-US-macOS-arm64-1.0.7.zip`
- Intel Mac：`Apple-Store-Inventory-Monitor-US-macOS-Intel-1.0.7.zip`
- 对应源码：`Apple-Store-Inventory-Monitor-US-source-1.0.7.zip`

解压后把 `Apple Store Inventory Monitor US.app` 放入“应用程序”。使用同一个 Bundle ID 和配置目录，替换旧版后原有监控设置仍可读取。应用为 ad-hoc 签名，未经过 Developer ID 公证；若 macOS 拦截，请在 Finder 中按住 Control 点击应用并选择“打开”。完整说明见 [README_US.md](https://github.com/yuanruoyu515/apple-store-inventory-monitor/blob/v1.0.7-us.1/README_US.md)。

Apple 官方购买页目前显示 Duo 于 2026-10-16 上午 5 点（太平洋时间）开始预购，10 月 23 日发售。取货接口开放前可能显示“即将发售”或“暂无数据”；Apple HTTP 541 拦截仍可能发生，程序不能保证查询始终被 Apple 接受。

基于 `suversal/apple-store-inventory-monitor` v1.0.6，继续按 GPL-3.0-or-later 发布。
