# Apple Store Inventory Monitor US v1.0.8-us.1

修复 Duo 预购开始后，监控列表全部显示“响应解析失败”的问题。

- 支持 Apple 的 `pickupDisplay: default` 业务状态，显示“取货待公布”，不再误报解析错误或触发故障退避。
- 保留 Apple 原始取货说明；例如 `Check back for availability on 10.24` 会显示“10/24 再查”。这不是可取货日期承诺，更不是有货或无货的结论。
- 待公布状态继续轮询，不发送有货通知；后续明确可取货时仍正常提醒。
- 美国站 `Mon, Jan 25` 等英文送货日期按 Apple 的编码年月日显示，正确处理跨年。
- 修复较长取货状态标签与门店名称重叠的问题，小窗口可横向滚动表格。

## 下载与安装

- Apple 芯片 Mac：`Apple-Store-Inventory-Monitor-US-macOS-arm64-1.0.8.zip`
- Intel Mac：`Apple-Store-Inventory-Monitor-US-macOS-Intel-1.0.8.zip`
- 对应源码：`Apple-Store-Inventory-Monitor-US-source-1.0.8.zip`

完全退出旧版后，解压并将 `Apple Store Inventory Monitor US.app` 替换到“应用程序”。Bundle ID 和配置目录不变，已有门店、型号、Bark 及声音设置会保留。应用采用 ad-hoc 签名，未经过 Developer ID 公证；如被 macOS 拦截，可在 Finder 按住 Control 点击应用并选择“打开”。完整说明见 [README_US.md](https://github.com/yuanruoyu515/apple-store-inventory-monitor/blob/v1.0.8-us.1/README_US.md)。

保留 269 家美国门店和 40 个美国 SKU。Apple 的 HTTP 541 拦截仍可能发生，查询失败不会被视为无货。基于 `suversal/apple-store-inventory-monitor` v1.0.6，按 GPL-3.0-or-later 发布，随附对应源代码。
