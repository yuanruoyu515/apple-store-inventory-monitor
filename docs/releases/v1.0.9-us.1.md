# 果到雷达 · 美加修改版 v1.0.9-us.1 🇺🇸 🇨🇦

**yuanruoyu515 维护的修改版，现已支持加拿大。美国和加拿大共用一个 macOS 安装包。请下载本仓库的版本，不要下载上游原版。**

[完整介绍与截图](https://github.com/yuanruoyu515/apple-store-inventory-monitor#readme) · [加拿大使用说明](https://github.com/yuanruoyu515/apple-store-inventory-monitor/blob/v1.0.9-us.1/README_CA.md) · [Threads @realtimyry](https://www.threads.com/@realtimyry)

## 新增加拿大支持

- 地区中增加 **Canada**，内置 28 家官方门店，可按省、城市、店名搜索。
- 支持加拿大 iPhone Duo、18 Pro、18 Pro Max，共 40 个独立 `VC/A` SKU，覆盖容量和颜色。
- 使用加拿大 `/ca` 查询、购物袋与商品页，不混用美国料号或美国运营商参数。
- 支持现有 Bark、声音、打开购物袋、暂停、限速与失败退避功能；待公布与错误不会被误报为有货。
- 修复快速切换地区时旧目录请求覆盖新地区的风险。切换 Canada 不删除现有美国监控。

完全退出旧版，解压后替换“应用程序”中的 **`Apple Store Inventory Monitor US.app`**。为兼容旧版，本次保留 US 应用文件名、Bundle ID 与配置目录；窗口改为「果到雷达 · 美加版」。原有美国监控、Bark、声音及其他设置会保留。

安装包采用 ad-hoc 签名，没有 Developer ID 签名及 Apple 公证。被拦截时，在“系统设置 → 隐私与安全性”确认本应用后选择“仍要打开”。安装前请确认来源与 SHA-256 校验文件。需要已安装的 Chrome／Edge，且 Mac 保持唤醒。

## 说明

发布前已通过 206 项 Rust 回归测试、27 项前端／目录测试、TypeScript 与 Vite 构建、clippy 零告警检查，并用真实 Chromium 会话完成加拿大 → 美国 → 加拿大的三门店查询验证。该验证只说明查询链路在测试时可用，不保证后续库存或网络状态。

本版新增的是加拿大**门店取货**支持，没有新增加拿大邮编送货查询。送货日期仅显示 Apple 本次返回的信息，不能据此推断门店库存。HTTP 541 拦截仍可能出现，查询失败不等于无货。软件不预留库存、不自动付款，最终以 Apple 结账结果为准。

保留 269 家美国门店与 40 个美国 SKU。基于 `suversal/apple-store-inventory-monitor` v1.0.6，继续按 GPL-3.0-or-later 发布；Assets 随附对应源码、使用说明和校验文件。
